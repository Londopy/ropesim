compute_effective_friction(device: 'BelayDevice', force_kn: 'float')

Compute the effective friction coefficient for ``device`` at ``force_kn``. For sliding devices this returns the constant value from ``BELAY_FRICTION_COEFFICIENTS``. For guide-mode (self-locking) devices the model is:: mu_eff = min(mu_base + k_lock * force_kn, mu_max) This captures the real behaviour where the device locks harder as the falling climber loads the rope: at low forces the device slips slightly (some rope pays out, reducing peak force); at high forces it locks fully. ---------- device : BelayDevice The belay device in use. force_kn : float The instantaneous rope force at the device (kN). Pass the *current* Returns ------- float Effective friction coefficient in [0, 1).

peakforce estimate when iterating to self-consistency.
