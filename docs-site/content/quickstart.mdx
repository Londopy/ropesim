## 1. Install

```bash
pip install ropesim
```

## 2. Pick a rope

The database ships 25 real EN 892 spec sheets:

```python
from ropesim import Rope

rope = Rope.from_db("Beal Joker 9.1 Dry")
print(rope.spec.impact_force_kn)     # 9.0  (manufacturer EN 892 value)
print(rope.effective_stiffness())    # length-normalised stiffness, kN

# or search
light_ropes = Rope.search(max_diameter=9.0, dry_treated=True)
```

## 3. Simulate a fall

```python
from ropesim import Fall, FallConditions, BelayDevice

fall = Fall(
    rope=rope,
    conditions=FallConditions(
        climber_mass_kg=80,
        fall_distance_m=4.0,     # how far you fall
        rope_out_m=8.0,          # rope between belayer and you
        belay_device=BelayDevice.GRIGRI,
    ),
)

print(f"fall factor : {fall.fall_factor:.2f}")   # 0.50
print(f"peak force  : {fall.peak_force:.2f} kN")

result = fall.simulate()      # RK4 damped-spring integration in Rust
curve = fall.force_curve_numpy()
```

A fall factor of 0.5 with a GriGri lands around 5–6 kN — a hard but normal
sport fall. The UIAA limit on the climber is 12 kN.

## 4. Try the v3 physics

```python
from ropesim import (
    twin_rope_forces, knot_strength_factor,
    fall_probability, dynamic_belay_reduction,
)

# Twin ropes through one piece share the load
fa, fb = twin_rope_forces(20.0, 20.0, mass_kg=80, fall_factor=1.0)

# A clove hitch keeps ~62% of rated strength
factor = knot_strength_factor("clove_hitch", diameter_mm=9.8)

# Will you fall on a 5.12a if you redpoint 5.11d? (~57%)
p = fall_probability(12.1, 11.4, style="sport")

# A 55 kg belayer soft-catching an 80 kg climber
reduction = dynamic_belay_reduction(80, 55, "atc", soft_catch_technique=True)
```
