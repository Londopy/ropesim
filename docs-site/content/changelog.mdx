The canonical changelog lives in
[`CHANGELOG.md`](https://github.com/Londopy/ropesim/blob/main/CHANGELOG.md)
(Keep a Changelog format — parseable with the
[`patchnotes`](https://pypi.org/project/patchnotes/) library).

## 3.0.0 — highlights

- **Native C++ Qt6 GUI** replaces the PySide6 app: 60 fps OpenGL rope
  renderer, native force plots, single-binary installers for
  Windows/macOS/Linux.
- **Dual FFI**: the Rust core now exports a plain C ABI (cbindgen) alongside
  PyO3.
- **New physics**: twin/half rope interaction, knot strength reduction,
  sheath abrasion accumulator, fall probability & daily exposure model,
  full dynamic belayer.
- **Terminal UI**, this documentation site, contribution infrastructure,
  and Colab-ready notebooks.

The release notes on GitHub are generated from this same file by
[`scripts/release_notes.py`](https://github.com/Londopy/ropesim/blob/main/scripts/release_notes.py),
which parses it with `patchnotes` and groups the changes by type.

```python
import patchnotes

cl = patchnotes.parse_file("CHANGELOG.md")   # or Changelog.from_github("Londopy/ropesim")
latest = cl.latest
print(latest.version, latest.release_date)   # 3.0.0 2026-07-08
for change_type, entries in latest.by_type.items():
    print(change_type, len(entries))
```
